# Strong emphasis

Text in ***bold italic***, which Pandoc reads as strong around emphasis.

Underscores too: ___bold italic___, and the unambiguous forms **_strong emphasis_** and _**emphasized strong**_ stay as prettier prints them.

A run split at one end: ***strong** then emphasis*, ***emphasis* then strong**, *emphasis then **strong***, and inside a word: foo***bar***baz.

Inside other emphasis, the inner emphasis takes `*` and touches strong: _a ***b*** c_.
