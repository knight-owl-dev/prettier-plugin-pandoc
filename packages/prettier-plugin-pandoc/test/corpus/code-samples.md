# Code samples

A sample tagged with a language prettier formats is reformatted under
embedded formatting, and printed as written without it:

```yaml
title:    A Book
authors: [ One,   Two ]
```

```json
{"formats":["pdf","epub"]}
```

An untagged sample, or one in a language prettier does not format, prints as
written either way:

```
title:    kept   as   written
```

```lua
local  x  =  1
```
